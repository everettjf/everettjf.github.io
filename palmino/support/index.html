Palmino support

Getting started

Add your own compatible model provider and API key in Settings. Choose a model before starting a conversation. Provider keys remain in Keychain.

Tools and connections

Enable only the Apple capabilities, MCP servers, and optional Linux tools you intend to use. Review confirmation prompts for sensitive actions and check the activity history when diagnosing a tool result.

Contact

Email xnuapp@gmail.com with the app version, device, iOS version, and steps to reproduce. Do not send provider keys or private conversations.
