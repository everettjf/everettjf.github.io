Titled support

Create a PDF

Open Titled and tap + to paste a web address, or choose Save with Titled from Safari’s share sheet. Wait for the preview, confirm the content, and tap Create PDF. You can share the result, open it, or rename it under More.

Missing or incomplete content

Some websites require login, block printing, or load images only after scrolling. Check the preview before creating a PDF. Reload and try again after restoring your network connection. If a page remains incomplete, use the website’s own export or print feature.

Find and rename saved files

The library includes local and iCloud PDFs as well as files created by the share extension. Search by filename or change the layout and sort order under View Options. An iCloud document may need downloading before opening. To rename, use More after conversion or long-press a file in the library.

Report a problem

Email xnuapp@gmail.com with the app version, iOS or iPadOS version, device model, and steps to reproduce the issue. Include a public sample URL only if you are comfortable sharing it. Please do not send passwords or private PDFs.
